# 怪物与动作设定

- 需求编号：`ART-MONSTER`；负责方：美术。
- 职责修订：`0.3.0`；目录与代码格式：`0.2.0`。
- 当前状态：未开始。此目录是规划入口，不代表功能、资源或编辑器验收完成。
- 修改范围：`art/monsters/`；先读根README、docs/responsibility_plan.json和相关契约。

## 职责与范围

这是同一个美术设定包中的内容专题。只交设定参考、规格与说明；实际模型、骨骼动画和Lua归策划，共享UI程序归程序。

美术设定交付包的怪物专题：每种怪物交付造型、材质、装饰与动作设定；巡逻、索敌、攻击、受击和寻路实现属于策划。

## 需要完成

- 每种怪物以完整设定呈现，说明体型、轮廓、正侧背、表面材质和装饰细节。
- 怪物动作设定覆盖正常巡逻、警觉、攻击前摇、攻击表现、恢复与受击。
- 需要特殊状态的怪物补充冲刺、附着、变形、免疫反馈或退场姿态的参考。
- 攻击方向、危险区域与可读前摇在设定中明确，策划据此完成实际判定和动作时序。
- 提供视野提示、攻击提示和命中表现的视觉方向，不在美术任务中实现检测算法。
- 怪物模型、骨骼、动画文件及专属 Lua 统一由 DES-MONSTER 制作；美术负责参考与外观确认。

## 核心交付

- 各怪物造型、比例、色彩、材质与装饰设定
- 巡逻、发现目标、攻击、受击、失去目标与死亡或退场的动作参考
- 怪物特殊形态与技能特效的设定说明

## 目录与引用

参考图、动作关键姿态、色材与标注使用小写英文文件名；中文用于展示标题。三个专题统一版本并一起交付。

文件使用项目根相对路径；代码访问经公共接口与注册ID，不引用个人绝对路径或其他实体controller。公共API/字段变更先放docs/change_requests/，由程序主框架统一发布。

## 编辑器关注

- 怪物轮廓在墓穴照明、暗部与角色视距下保持辨识度。
- 特殊形态需说明可拆分部件和运动方式，便于策划选择骨骼或其他动画方案。
- 视野与攻击区域提示采用项目统一视觉语言，具体检测数据由策划配置。

## 验收（全部待执行）

先对齐设定和公共契约，再做对象交付及系统合入；验收记录写实际步骤和结果。未测试的模型、UI、行为、存档或多人能力保持待验收。
