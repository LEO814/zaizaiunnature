# 武器道具外观、UI/UE 与零碎资源设定

- 需求编号：`ART-VISUAL`；负责方：美术。
- 职责修订：`0.3.0`；目录与代码格式：`0.2.0`。
- 当前状态：未开始。此目录是规划入口，不代表功能、资源或编辑器验收完成。
- 修改范围：`art/visual_ui/`；先读根README、docs/responsibility_plan.json和相关契约。

## 职责与范围

这是同一个美术设定包中的内容专题。只交设定参考、规格与说明；实际模型、骨骼动画和Lua归策划，共享UI程序归程序。

美术设定交付包的视觉专题：武器与道具外观、UI/UE、图标、提示、特效和场景零碎资源的设定均集中管理；实际物件模型和业务 Lua 由策划，界面及全局 UI 程序由程序实现。

## 需要完成

- 武器与道具放在同一专题内，说明外观、材质、识别色、手持姿态与使用表现。
- 不增加独立装备或护甲设定项；武器持握和道具使用状态与角色动作专题对应。
- UI/UE 覆盖页面结构、操作路径、焦点、选中、禁用、加载、错误与确认反馈。
- 统一图标的轮廓、色彩、尺寸适配、安全边距和品质或数量标记规则。
- 提供宝箱、机关、门、入口、出口以及场景零碎物件的风格设定，实际场景模型与互动实现归 DES-SCENE。
- 匹配、探索、受伤、物品使用、背包操作和比赛结算提示使用统一视觉语言。
- 设定输出为可供制作的参考图、布局图、状态说明与必要规格，不要求美术承担模型导出或 Lua 程序。

## 核心交付

- 武器与道具外观、材质、尺寸和持握设定
- 局内 HUD、背包、局前背包、仓库、商店、匹配与结算界面的 UI/UE 设定
- 道具图标、按钮状态、提示、特效和场景交互物视觉设定

## 目录与引用

参考图、动作关键姿态、色材与标注使用小写英文文件名；中文用于展示标题。三个专题统一版本并一起交付。

文件使用项目根相对路径；代码访问经公共接口与注册ID，不引用个人绝对路径或其他实体controller。公共API/字段变更先放docs/change_requests/，由程序主框架统一发布。

## 编辑器关注

- UI 设定关注编辑器支持的分辨率适配、输入方式和安全区域，具体能力经验证后锁定。
- 图标和提示需在暗场景及不同界面底色上清晰可读。
- 交互反馈需明确由对象触发还是全局界面触发，便于策划与程序接入。

## 验收（全部待执行）

- [ ] 武器与道具外观设定统一且能关联对应动作参考。
- [ ] UI/UE 覆盖主要页面与正常、禁用、错误等状态。
- [ ] 图标与零碎资源设定采用统一规格。
- [ ] 场景交互物视觉设定能区分可操作与不可操作状态。
- [ ] 策划及程序能根据设定分别制作物件与界面。
- [ ] 所有视觉专题资源归入同一个美术包，未新增独立装备需求。

## 协作顺序

先对齐设定和公共契约，再做对象交付及系统合入；验收记录写实际步骤和结果。未测试的模型、UI、行为、存档或多人能力保持待验收。
