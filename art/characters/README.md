# 角色与动作设定

- 需求编号：`ART-CHARACTER`；负责方：美术。
- 职责修订：`0.3.0`；目录与代码格式：`0.2.0`。
- 当前状态：未开始。此目录是规划入口，不代表功能、资源或编辑器验收完成。
- 修改范围：`art/characters/`；先读根README、docs/responsibility_plan.json和相关契约。

## 职责与范围

这是同一个美术设定包中的内容专题。只交设定参考、规格与说明；实际模型、骨骼动画和Lua归策划，共享UI程序归程序。

美术设定交付包的角色专题：完成外观、比例、材质、挂点位置和动作参考；实际模型、骨骼、动画与 Lua 由策划制作。

## 需要完成

- 统一角色正侧背造型、身高比例、轮廓与物件持握姿态，不另设独立装备或护甲系统。
- 角色动作设定说明待机、走跑、转向、受击、倒地以及探索交互动作的视觉目标。
- 武器和道具使用动作说明双手配合、手持位置、身体重心和动作起止姿态；具体时序由策划落实。
- 明确角色可读性：当前动作、受伤状态与不可操作状态在画面上能被分辨。
- 以示意图、关键姿态和文字描述说明动作；不在美术任务中要求实际绑定、动画导出或行为代码。
- 角色专题与怪物、武器道具及 UI 专题归入同一个美术设定交付包，统一修订。

## 核心交付

- 角色外观与比例设定、色彩材质说明
- 待机、移动、受击、倒地与使用武器道具的动作参考
- 动作姿态、过渡关系和挂点的设定说明

## 目录与引用

参考图、动作关键姿态、色材与标注使用小写英文文件名；中文用于展示标题。三个专题统一版本并一起交付。

文件使用项目根相对路径；代码访问经公共接口与注册ID，不引用个人绝对路径或其他实体controller。公共API/字段变更先放docs/change_requests/，由程序主框架统一发布。

## 编辑器关注

- 设定需兼顾编辑器内相机距离、俯仰视角与角色遮挡。
- 标注持握、头部和身体等挂点的视觉位置，节点名称由制作与接入契约统一。
- 动作参考应能被策划转换为可导入的动画，导出格式通过最小导入验证后确定。

## 验收（全部待执行）

- [ ] 角色正侧背设定一致，比例和材质说明齐全。
- [ ] 待机、移动、受击、倒地与交互动作均有可执行参考。
- [ ] 武器和道具动作参考能与外观专题对应。
- [ ] 受伤与不可操作状态视觉辨识清晰。
- [ ] 策划能够按设定制作模型与动作，关键姿态不存在歧义。

## 协作顺序

先对齐设定和公共契约，再做对象交付及系统合入；验收记录写实际步骤和结果。未测试的模型、UI、行为、存档或多人能力保持待验收。
